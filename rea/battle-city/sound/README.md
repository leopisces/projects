# Battle City 音乐/音效逆向

从 ROM 里完整解出音序引擎和数据，重放为 WAV。**没有采样原版音频，是用 APU 合成器按寄存器时序重新合成的。**

```
tools/sound.py        解码器 + APU 合成器
sound/seq_00..27.wav  28 个音序槽单独渲染
sound/*.wav           合成后的完整曲子
sound/sequences.txt   每个槽的记谱（音名/频率/时长/循环）
```

## 音序引擎（逆向自 `$EA7E` / `$EB11`）

### 触发方式

游戏往 `$0300 + N`（N = 0..27）写 1，该槽下一帧开始播。

### 引擎每帧两趟

| 趟 | 做什么 |
|---|---|
| Pass 1 | 看每个槽数据块 byte0：`1-4` = 有新音符待写 → 抢硬件声道写寄存器；`5-8` = 已写；`0` = 空闲。低槽号优先。没被抢的声道写 `$4000 = $10`（静音） |
| Pass 2 | 看 `$0300+N`：`1` = 启动（读头部）；`>=2` = 递减时长计数，归零则读命令 |

**1 帧延迟**：Pass 2 解出的音符让 byte0 = 声道号，下一帧 Pass 1 才真正写 APU。

### 序列格式

```
头部 4 / 5 字节:
  b0 = 硬件声道   1=方波1  2=方波2  3=三角  4=噪音
  b1 = $4000 值（duty/包络/音量）
  b2 = $4001 值（扫频）
  b3 = $4003 值（含长度计数器位）
  [仅 b0==4 时多 1 字节 → 噪音周期]

命令流:
  $00-$5F   音符：idx = b>>3（12 音，A 起半音递增），shift = b&7
            周期 = NoteFreqTable[idx] >> shift
            频率 = 1789773 / (16 × (周期+1))
  $60       复位时长计数
  $61-$E7   设时长 = b - $60 帧（60.1 帧/秒）
  $E8       停止本槽
  $E9/$EA   改 b1 低 6 位（音量/包络）
  $EB       改 b1 低 4 位（音量）
  $EC       改扫频
  $ED       改 b3
  $EE       改整个 b1
  $EF       清零 3 个循环计数器
  $F0-$F2   循环：<次数> <回跳位置>（三个独立循环层）
  $F3-$FF   跳过 1 字节
```

### 常用表

```
$ECFE  ChannelPtrTable   28 × u16  音序数据指针
$ECE6  NoteFreqTable     12 个周期值（大端）
       07F2 0780 0714 06AE 0643 05F4 059E 054E 0502 04BA 0476 0436
       = A1 起半音递增到 G#2
```

### 硬件声道优先级

同一硬件声道被多个音序槽抢时，**槽号小的赢**；没被抢的声道每帧被写成音量 0。这就是为什么只有一个槽在播时声音不会叠加。

### 主旋律记谱（音序 1，方波1，前 24 音）

```
C5  D5  D#5  C5  D5  D#5            (每音 8 帧 ≈ 133ms)
D#5 F5  G5   D#5 F5  G5
F5  G5  A5   F5  G5  A5            (A5 起升八度 shift=4)
G#5 A#5 C6   G#5 A#5 C6
C6 (24 帧) ...
```

三角（音序 2）走低音贝斯，方波2（音序 3）走和声 —— 三条线循环长度一致，合起来就是完整曲子。

## 合成器实现要点

### 已修的三个真错误（都会让声音明显不对）

| # | 错误 | 表现 |
|---|---|---|
| 1 | 音符处理后把 `byte0` 写成 `hw+4`（应为 `byte0 -= 4`）| **每个声部只响第一个音就卡死** → 只有几个孤立单音 |
| 2 | 三角通道按方波逻辑算音量，得到 `vol=0` 被跳过 | **整条贝斯线缺失**，只剩旋律 |
| 3 | 音量包络按 60Hz 走（实际是 240Hz 帧序列器）| 拨奏衰减慢 4 倍，音与音糊在一起 |


- **方波**：4 种占空比 `12.5% / 25% / 50% / 75%`，`$4000` 的 bit7-6 选
- **三角**：32 级阶梯波，频率 = `CPU/(32×(T+1))`
- **噪音**：15 位 LFSR，周期表取自 `$400E` 的 16 档
- **音量**：`$4000` bit4 = 常数音量模式，取 bit3-0；否则按包络（这里简化为满音量）
- **音量包络**：`$4000` bit4=0 时音量从 15 起按 `period/240` 秒一档衰减，`period=1` 时约 62ms，这就是原版的"拨奏"音色
- **长度计数器**：`$4003` 高位查 `LENGTH_TBL`，以 120Hz 递减，归零即静音
- **混音**：用 NESdev 社区标定的非线性公式，而不是简单相加
  ```
  pulse = 95.88 / (8128/(p1+p2) + 100)
  tnd   = 159.79 / (1/(t/8227 + n/12241) + 100)
  ```
  简单相加会让低音过响、整体失衡
- **三角波**：$4008 没有音量控制，只能被长度计数器关掉；相位推进用 `CPU/32(T+1)`（不是方波的 `/16`）
- 采样率 44100，帧率 60.0988（NTSC）
- 未实现：扫频（本作 `$4001 = $7F`，E 位为 0 表示扫频关闭，所以不影响）
