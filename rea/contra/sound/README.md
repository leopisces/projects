# Contra（魂斗罗）音频导出

全部由 ROM 里的**声音引擎本身**跑出来的：不套用 battle-city 的音序格式，
而是直接用带 APU 的 6502 解释器执行引擎代码（`tools/play_sound.py`）。

## 命令表 `$8920`（3 字节/项）

```asm
$880A: AD 17 87   LDA $8717     ; 基址是代码字节：$8717 处的 "20 89 8A"
$880D: 85 EC      STA $EC       ;   = JSR $8A89，$20/$89 正好被当基址读
$8818: AD 22 01   LDA $0122     ; A = id
$881C: 65 EC      ADC $EC
$8824: 85 ED      STA $ED       ; $EC += 3*id（循环 3 次）
$882E: B1 EC      LDA ($EC),Y   ; flags
$8830: 4A 4A 4A   LSR A ×3
$8833: 29 03      AND #$03      ; 通道数 = (flags>>3)&3
$8840: 29 07      AND #$07      ; 通道号 = flags&7
```

| 位 | 含义 |
|----|------|
| bits 0-2 | 目标通道号（0=P1, 1=P2, 2=三角, 3=噪音, 4/5=扩展） |
| bits 3-4 | 通道数-1（0 = 单通道） |

`id >= $82`(130) 直接 `RTS` 无效；`id = $7F-$81`(127-129) 走 `$88DA` 特殊路径。

## 分轨关系（重要）

部分 id 是同一曲的**单声部分轨**，换关时只重载变化的声部：

- id 3（ch0+ch1+ch2 完整）= id 4(ch1) + id 5(ch2)
- id 7（ch0+ch1+ch2 完整）= id 8(ch1) + id 9(ch2)
- id 16（ch4+ch1）= id 17(ch1) + 一个 ch4 分轨
- id 32（ch4+ch1+ch3）= id 33(ch1) + id 34(ch3) + ch4 分轨

## ⚠️ 已知重复

id 119 与 id 123 三个通道的指针**完全相同**（`$9827/$986F/$98B3`），
即同一首曲子登记了两次。

```powershell
python tools/export_sound.py           # 导出全部 127 个
python tools/export_sound.py 3 7 90    # 只导指定 id
```
