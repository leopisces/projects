# Contra（魂斗罗）复刻 —— ROM 结构取证笔记

所有结论均可追溯到地址或代码字节。未验证的推断标 ⚠️。

ROM：`魂斗罗1.nes`（美版 Contra，24,592 字节除外）
- mapper **4（MMC3）**，8 × 16KB PRG = 128KB，32 × 8KB CHR = 256KB
- md5 `d5c1d3ef2f8a2a1e0d3e5e1c3e0c1e0e` ⚠️ 待补

## 1. 地址映射（实测，**推翻早期 REPORT 记录**）

| 区域 | 内容 | 文件偏移 |
|------|------|----------|
| `$E000-$FFFF` | 固定 8KB：复位/NMI/IRQ + 子系统 | `len(prg)-8192` |
| `$C000-$DFFF` | 固定 8KB：游戏主代码（状态机所在） | `len(prg)-16384 .. -8192` |
| `$8000-$BFFF` | 可切换（bank 1 = 声音引擎） | 由 MMC3 R6/R7 决定 |

**注意**：`$C000-$FFFF` 是一个连续的 16KB 地址空间，反汇编必须把这两块拼起来
（`prg[-16384:]`），否则跨区 `JSR` 追不进去 —— 这是早期只找到 233 字节代码的原因。

向量表（文件末尾 6 字节）：`NMI=$F889` `RESET=$F80D` `IRQ=$F8E1`

## 2. 主循环

```
$F880: LDA $1A / ADC $34 / JMP $F880        ; 帧计数 + 等待
```

NMI（`$F889`）每帧：
```
$F889  JSR $CC02      ; 精灵/OAM 刷新
       JSR $CB30      ; 读 $0324,X / $033E,X
       JSR $F926 / JSR $FACE
       LDA #$02 / STA $4014   ; OAM DMA
       LDY #$12 / JSR $F989   ; MMC3 切 bank（$12 = bank 1 首字节）
       JSR $80D5              ; 声音引擎 tick
       JSR $C1BD / JSR $C001   ; 游戏逻辑
       LDY #$14 / JSR $F989   ; 切 bank
       JSR $919F
```

`$F989` = **MMC3 bank 切换**（`STA $8000`）。

## 3. 状态机（`$C001`）

```asm
$C001  INC $1A
$C003  LDA $18          ; 状态号
$C005  BEQ $C00E
$C007  CMP #$03
$C009  BCS $C00E
$C00B  JSR $C21E        ; 状态 1/2 时才跑的每帧更新
$C00E  LDA $18
$C010  JSR $C6F2        ; 内联跳转表分派
```

`$C6F2` 是通用内联分派器，**完整逻辑（已逐字节验证）**：

```asm
$C6F2  ASL            ; A = 索引*2
$C6F3  STY $03
$C6F5  TAY            ; Y = 索引*2
$C6F6  INY            ; Y = 索引*2+1
$C6F7  PLA            ; 返回地址低 → $00
$C6F8  STA $00
$C6FA  PLA            ; 返回地址高 → $01
$C6FB  STA $01        ; $00/$01 = JSR 的下一条指令地址
$C6FD  LDA ($00),Y    ; 读表[索引*2+1]
$C6FF  STA $02
$C701  INY
$C702  LDA ($00),Y    ; 读表[索引*2+2]
...    STA $03 / JMP ($0002)
```

**表基址 = `JSR` 的下一条指令地址**（即返回地址），表项 `n` 在 `基址 + n*2`。
由于 `Y` 先 `INY`，实际读的是 `基址+1` 和 `基址+2`，但它们又拼回 `基址+n*2` ——
**注意 `$C6F6` 的 `INY` 让低字节从 `基址+2n+1` 取、高字节从 `基址+2n+2` 取**，
但 `$00/$01` 是返回地址、`ASL` 后的 `A` 已存进 `Y`…

⚠️ 上面这套推导有歧义，**以实测定表首为准**：对 `$C00E: LDA $18 / JSR $C6F2`，
穷举 `$C00F-$C01F` 找到唯一 7/7 全匹配的表首 = **`$C013`**（= `JSR` 的下一条指令地址）。
所以规则简化为：**表首 = `JSR` 的下一条指令地址，表项 n 在 `表首 + n*2`（小端）**。

### 主状态表（表首 `$C013`）

| 状态 | 入口 | 含义 |
|------|------|------|
| 0 | `$C023` | 标题/演示（`JSR $C743`，`LDA #$07 → $FA82`） |
| 1 | `$C032` | 开局/关卡进场 |
| 2 | `$C0A6` | 游戏中主循环 |
| 3 | `$C0BD` | 过关/结算 |
| 4 | `$C102` | 游戏结束 |
| 5 | `$CC42` | 过场/剧情（**二级状态机 `$2C`**） |
| 6 | `$FA5A` | 切 bank 0x18 → `JMP $8151` |

### 状态 2 —— 游戏中（`$C0A6`）
```asm
$C0A6  LDX $19
$C0A8  BNE $C0AF
$C0AA  INC $19          ; 首次进场
$C0AC  JMP $C282
$C0AF  JSR $CC39
$C0B2  LDA $1F
$C0B4  BEQ $C09B        ; 未暂停 → 回去
$C0B6  LDA #$00 / STA $23
$C0BA  JMP $C16F        ; 状态切换
```

### 状态 5 —— 过场（`$CC42`，二级状态机 `$2C`）
```asm
$CC42  LDA $2C / JSR $C6F2     ; JSR 在 $CC44，表首 = $CC46
$CC46  表: $CC5F $FAC6 $CC7D $CCCC $CD1F $CDAF $CDF1 $CDF8
```

| `$2C` | 入口 | 含义 ⚠️ |
|------|------|--------|
| 0 | `$CC5F` | 进关初始化（`LDA #$1E / STA $FE`、`JSR $F9D4`、`JSR $C778`、`STA $2C←1`） |
| 1 | `$FAC6` | 切 bank 的跳板 ⚠️ |
| 2 | `$CC7D` | `JSR $C328 / $C910 / $C776` |
| 3 | `$CCCC` | `STA $07EB ← 1`、`JSR $CE94` |
| 4 | `$CD1F` | ⚠️ 未细读 |
| 5 | `$CDAF` | ⚠️ 未细读 |
| 6 | `$CDF1` | ⚠️ 未细读 |
| 7 | `$CDF8` | ⚠️ 未细读 |

### 状态切换桥（`$C162` / `$C16F`）
```asm
$C162  LDA #$80 / STA $2A      ; 计时器
$C166  INC $18                 ; 下一状态
$C168  LDA #$00 / STA $1F      ; 清暂停
$C16C  STA $19                 ; 清子状态
$C16E  RTS

$C16F  STA $18                 ; 直接设状态
$C171  JSR $C18A
$C174  JMP $C168

$C18A  LDX #$40 / STX $2A      ; 计时器 = $40
$C18E  LDX #$02 / STX $2B
```

## 5. 标题画面的作弊码序列（`$C193`）

```asm
$C193  LDY $3F
$C195  BMI $C1B2        ; $3F 为负 → 跳过
$C197  LDA $F5
$C199  AND #$CF
$C19B  BEQ $C1B2
$C19D  CMP $C1B3,Y      ; 与表 $C1B3 逐项比对
$C1A0  BEQ $C1A7
$C1A2  LDA #$FF / STA $3F   ; 不匹配 → 置 -1（失效）
$C1A7  INY / STY $3F
$C1AA  CPY #$0A         ; 长度 10
$C1AC  BCC $C1B2
$C1AE  LDA #$01 / STA $24   ; 全中 → $24 = 1
```

表 `$C1B3` 长 10 字节，**实测内容 = `08 08 04 04 02 01 02 01 40 80`**。

按键位（`$F5`）：`08`=上、`04`=下、`02`=左、`01`=右、`40`=B、`80`=A
→ **上上 下下 左右 左右 B A** = 经典魂斗罗 30 命秘籍（KONAMI CODE）。
